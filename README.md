# SelfShare

Compartilha a tela ou um jogo com a galera por um link no navegador.

**Baixar:** [SelfShare-Setup.exe](https://github.com/Marcostk/selfshare-releases/releases/latest/download/SelfShare-Setup.exe) (Windows 11, ou Windows 10 build 20348+)

Depois de instalado, o app confere este repositório a cada 24 horas e se atualiza sozinho
(dá pra desligar no menu do ícone perto do relógio). Pra transmitir precisa de um convite
de quem cuida do servidor; pra assistir, só o link.
